# Reading Comprehension Tests

| Test | Difficulty | Description |
|------|------------|-------------|
| RC-01 | Easy | Read a technical document, answer precise questions |
| RC-02 | Medium | Extract structured data from unstructured report |
| RC-03 | Hard | Read 100K+ token codebase section, identify buried bug |
| RC-04 | Hard | Multi-document synthesis across 5 files |

Test prompts go here. Each test file contains:
- `prompt.md` — the instruction sent to the AI
- `input/` — real documents or code the AI must read
- `expected/` — properties of a correct answer (NOT the answer itself)
