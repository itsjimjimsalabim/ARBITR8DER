### Settings.json Schema (verified from cli.mjs source)

Accepted fields in `.openclaude/settings.json`:
- `permissions.defaultMode` — permission mode string
- `permissions.allowBypassPermissionsMode` — boolean
- `permissions.additionalDirectories` — array of paths
- `permissions.skipDangerousModePermissionPrompt` — boolean
- `maxTurns` — integer, default 50
- `maxSteps` — integer
- `contextWindow` — integer (model context window)
- `allowedTools` — array
- `hooks` — object
