# ARBITR8DER

Local digital trading studio for AI-operated research, paper trading, and explicitly armed live execution.

This repo is the canonical workspace. Older separate agent folders are deprecated and should be treated as reference-only unless an explicit migration is requested.

Primary orientation docs:

- `docs/Theories_of_Operations.md`
- `docs/overwatch_workflow.md`
- `agents/codex/AWAKENING.md`

Safety baseline: no process may trade without an explicit ARMED wallet configuration and operator action. The intended default vessel state is `Full_Stop`.
