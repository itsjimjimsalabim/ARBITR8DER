# OpenClaude Startup Instructions

On startup, read and internalize the full content of `agents/agents.md`.

That file is the single source of truth for all AI agents in this project.
It contains project orientation, operating principles, directory layout,
build/test commands, and known issues. Treat it as your primary directive
file — it overrides any conflicting defaults.

Additional context files to read when making architecture changes:
- `agents/Product_Requirements_&_Theories_of_Operations.md`
- `agents/overwatch_workflow.md`
- `agents/github_connectivity.md`
